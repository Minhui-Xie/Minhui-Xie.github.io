# 课题组简介
课题组关注**人工智能与计算机系统的交叉**，方向包括：
1. 人工智能系统：
- 搜索、推荐、广告系统架构
- 大语言模型推理
- Agent系统
- KVCache存储
2. 向量存储系统：
- 索引构建加速
- 索引检索加速
- 新型向量应用
3. 新型存储/网络栈：
- GPU直通架构
- 内存语义架构

工作发表于 **SC、EuroSys、ATC、ASPLOS、SOSP、SIGMOD、VLDB** 等CCF-A类系统/数据管理顶会。

# 为什么推荐研究AI Infra系统方向？

- **有价值**：成果可落地于大规模集群，毕业年薪遥遥领先（周围系统方向博士均入选顶薪人才计划）。
- **可解释**：没有薛定谔的性能，只有确定的、可复现的实验结果；可以通过实验明确知道哪一步耗时多、哪一步是瓶颈，不用调参“求神拜佛”。**Measure then build.**
- **有挑战**：系统研究是计算机科学的“深水区”，没有经过训练的人搞不了。
- **“铁”饭碗**：应用层（LLM、Agent、向量）和硬件层（GPU 新特性、新硬件）双向驱动系统软件创新，永远有事情做。

# 我们期待什么样的同学

系统研究高度依赖**动手能力**和**把问题测清楚的习惯**，希望你：

- 对操作系统、计算机体系结构、存储、分布式系统、GPU / 高性能编程中的至少一类真正有兴趣；
- 愿意读代码、写代码、做实验、看profile，而不是无脑调Coding Agent；
- 能接受系统工作周期较长、需要反复定位瓶颈、反复改实现；
- 本科实习生尤其欢迎：**希望尽早进入科研或有出国深造意向**的同学。

以下经历会加分，但都不是硬性门槛：
- 高性能计算/ 操作系统 / 体系结构 / 编译 / 数据库等相关课程、系统类项目或竞赛
- GPU/RDMA/NVMe SSD等高性能硬件使用经验
